# Curbside Chaos

At BetaNYC's Mobility for All Abilities Hackathon on National Day of Civic Hacking 2019, I worked in a team to geocode and visualize over 30,000 location points from NYC OpenData’s parking location and 311 report datasets to map street and curbside usage by district. 

We used the Pandas and Shapely Python libraries to extract coordinates from the original data sets, and Kepler.gl to visualize points on a map of NYC.
